How the numbers work

tasks/week = weekly $ value ÷ $ per AA task. Cost per task comes from Artificial Analysis running its 10-eval Intelligence Index at list API prices, so it already folds in how many tokens each model burns at each effort. A token-hungry model is expensive per task even at a low per-token price.

Fable 5.1 bills against Claude limits at the same API rate but can use only part of the weekly limit (50% by default). On its own that caps it at that share of the Claude budget. In a mixed week the cap applies to the Fable part only.

Caveats

  • An AA task is a benchmark task, not your task. Use the ratios, not the absolute counts.
  • Weekly plan values are estimates and move when vendors change limits.
  • Rankings assume one model for the whole week. Build your week splits one shared budget between two.
  • Missing values: Sonnet 5.5 xhigh (all), Fable 5.1 medium and Astra xhigh cost, and several speeds. PRs with a source are welcome.
